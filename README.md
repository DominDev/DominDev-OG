Turn traffic into paying clients.

- **Semantic HTML**: Built the right way for long-term stability.

Be found by those who need you.
- **Rich Snippets**: Pre-configured Schema.org data (Person, LocalBusiness, FAQ) lets you take up more space in Google results.
- **Local SEO**: Geo-meta tags to target your specific city and region.
- **Open Graph**: Beautiful previews when shared on Facebook, Twitter, and LinkedIn.

## 💻 Development & Deployment

For developers or clients with the **Starter Bundle**:

```bash
# 1. Install Dependencies
npm install

# 2. Start Local Dev Server (Hot Reload)
npm run dev

# 3. Build for Production (Minify & Optimize)
npm run build
```

**Automated Pipelines:**
- `npm run optimize:images` - Generates responsive AVIF/WebP sets.
- `npm run optimize:video` - Compresses hero background videos.
- `npm run minify:css` - Shrinks stylesheets for faster delivery.
